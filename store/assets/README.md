Screenshots are actual 1280 × 800 captures with square corners. The settings images show the extension options; the release demo shows its real controls in a clearly labeled synthetic list, including Bug/PBI selection and compact copy icons first, checkboxes second, State before Title, and process-aware quick-copy actions. They contain no real organization, project, work-item, or signed-in user details. The promotional tile is brand artwork rather than a screenshot. A marquee and video are optional and are not included.

Suggested screenshot order: release selection demo, settings light, settings dark. The release demo is a project-owned fixture, not a signed-in Azure DevOps service capture. Keep organization-specific captures local; do not commit them to this public repository.
