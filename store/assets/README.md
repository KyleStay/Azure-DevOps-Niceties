# Store images

Upload these files in the Store listing tab:

| File | Use |
| --- | --- |
| `icon-128.png` | 128 × 128 extension icon |
| `promo-440x280.png` | Required small promotional tile |
| `settings-light-1280x800.png` | Screenshot: actual extension options, light |
| `settings-dark-1280x800.png` | Screenshot: actual extension options, dark |
| `release-selection-demo-1280x800.png` | Screenshot: actual release-selection controls in a clearly labeled synthetic sample |

Screenshots are actual 1280 × 800 extension-options captures with square corners. They contain no organization, project, work-item, or signed-in user details. The promotional tile is brand artwork rather than a screenshot. A marquee and video are optional and are not included.

Suggested screenshot order: release selection demo, settings light, settings dark. The release demo is a project-owned fixture, not a signed-in Azure DevOps service capture. Keep organization-specific captures local; do not commit them to this public repository.
