Azure DevOps Niceties

A Chrome extension for clean Azure DevOps work-item links, release-stage list selection and copying, selected estimate totals, and optional system theme matching.

Copy references as clickable titles, Markdown, IDs, URLs, or branch names. Release lists gain compact copy icons first, selection checkboxes second, State before Title, and copy shortcuts for backlog items with or without bugs across Azure DevOps processes. References use one line per item and inherit the destination's font.

Click a displayed work-item State to choose and save a new workflow state immediately, using your Azure DevOps permissions and normal workflow rules. Inline state editing can be turned off in the extension menu.

Select loaded work items to see separate Effort, Story Points, and Size totals, plus counts by type and state. Summaries start enabled and can be turned off in the extension menu.

Automatic theme matching follows your system when Azure DevOps starts with its standard light/default theme. Selected dark and high-contrast themes are preserved. Choose Automatic, On, or Off in the extension menu.

Copying and summaries start enabled. You can turn either off in the extension menu; saved opt-outs are preserved. The extension has no analytics or advertising.
