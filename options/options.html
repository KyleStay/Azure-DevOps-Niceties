System theme · Copying · Selection totals · State editing

Your work-item data

Enhanced copying reads work-item IDs, titles, types, and URLs locally and writes your chosen format to the clipboard. Release selections keep references in page memory while the list is open. Quick-copy shortcuts read project work-item type categories from your signed-in Azure DevOps organization. Copy as table reads field names when opened and the chosen items’ saved Title, State, and selected field when you copy. Parent context requests information from your signed-in Azure DevOps organization. Preferences can sync through Chrome. Work-item content is not sent to the publisher. No analytics or ads.

Selection summaries read the selected work-item rows and their displayed estimates, types, states, and assignments (which may contain names or email addresses) locally. No extra requests are made and no work-item data is saved.

Inline state editing reads the current work-item revision and workflow states when you open a state picker. Choosing a new state immediately saves it to Azure DevOps using your signed-in session and normal permissions and rules.
